# Stock Revenue Dashboard

A Python project analyzing historical stock prices and quarterly revenue data for Tesla and GameStop. It uses yfinance to retrieve stock data, web scraping with BeautifulSoup and pandas to collect revenue data, and Matplotlib to visualize stock-price trends.

## Notebook

[Open the final assignment notebook](https://github.com/shravaniwaghmare6868-web/stock-revenue-dashboard/blob/main/Final_Assignment_Stock_Revenue_Dashboard.ipynb)

## Topics covered

- Historical stock data extraction with `yfinance`
- Web scraping and revenue data cleaning with `BeautifulSoup` and `pandas`
- Stock-price visualization with `Matplotlib`
- Tesla and GameStop stock/revenue analysis

**Note:** Run the notebook in an environment with internet access and save the outputs before submitting if your course requires executed results.
